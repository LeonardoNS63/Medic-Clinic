# 🏥 Medic Clinic

## 🇧🇷 Português

Sistema de gerenciamento de clínica médica desenvolvido como projeto de estudo, com foco na integração entre um backend em **Java (Spring Boot)** e um frontend em **HTML, CSS e JavaScript**.

O objetivo do projeto é praticar conceitos de API REST, persistência de dados, validação de formulários e consumo de API via `fetch`.

### ✨ Funcionalidades
- Cadastro e consulta de pacientes
- Cadastro e consulta de médicos
- Validação de dados obrigatórios e únicos (email, telefone)
- Comunicação entre frontend e backend via API REST

### 🛠️ Tecnologias utilizadas
- **Backend:** Java, Spring Boot, Spring Data JPA, Spring Web
- **Banco de dados:** H2 / PostgreSQL (ajustar conforme configuração)
- **Frontend:** HTML, CSS, JavaScript
- **Build:** Maven

### 🚀 Como executar o projeto

**Pré-requisitos:**
- Java 17+
- Maven (ou usar o wrapper `mvnw` incluso no projeto)

**Passos:**
```bash
# Clone o repositório
git clone https://github.com/LeonardoNS63/Medic-Clinic.git

# Entre na pasta do projeto
cd Medic-Clinic

# Execute a aplicação
./mvnw spring-boot:run
```

O backend estará disponível em `http://localhost:8080`.

Para o frontend, abra os arquivos HTML com uma ferramenta como o **Live Server** (extensão do VS Code) ou outro servidor local de sua preferência.

## 🇬🇧 English

A medical clinic management system built as a learning project, focused on the integration between a **Java (Spring Boot)** backend and an **HTML, CSS, and JavaScript** frontend.

The goal of this project is to practice REST API concepts, data persistence, form validation, and API consumption using `fetch`.

### ✨ Features
- Patient registration and lookup
- Doctor registration and lookup
- Validation for required and unique fields (email, phone)
- Communication between frontend and backend via REST API

### 🛠️ Tech stack
- **Backend:** Java, Spring Boot, Spring Data JPA, Spring Web
- **Database:** H2 / PostgreSQL (adjust according to your configuration)
- **Frontend:** HTML, CSS, JavaScript
- **Build tool:** Maven

### 🚀 How to run the project

**Requirements:**
- Java 17+
- Maven (or use the included `mvnw` wrapper)

**Steps:**
```bash
# Clone the repository
git clone https://github.com/LeonardoNS63/Medic-Clinic.git

# Enter the project folder
cd Medic-Clinic

# Run the application
./mvnw spring-boot:run
```

The backend will be available at `http://localhost:8080`.

For the frontend, open the HTML files using a tool like **Live Server** (VS Code extension) or any other local server of your choice.
